🚀 iGuhit Vector Graphics Editor

A premium, client-side vector graphics web application utilizing HTML5, CSS3, JavaScript, and Paper.js. Engineered to match standard professional vector design environments.

Introduction

Welcome to iGuhit Vector! This application replicates the traditional multi-panel desktop workspace. You can draw path vectors, modify control anchor points, manage complex layer hierarchies, and style layouts using advanced fills and strokes.

Project Design Principles

The canvas acts as an endless pasteboard. The white rectangle in the center represents your exportable Artboard. You are free to draw off-artboard, zoom in/out, and pan around in all directions just like in professional vector suites.

How to Run the Application

The app runs completely client-side. The file structure consists of:

  • index.html: The skeletal workspace representing menus, panels, toolbar structures, and layout wrappers.
  • style.css: Theme styles defining the application's dark colors, input styles, grids, panel alignments, and responsiveness.
  • app.js: The orchestrator managing tools, mouse computations, layer states, undo stacks, and document exports.

To load the app, verify it is running on your local server: http://localhost:8000.

🛠️ Supported Tools & Shortcuts

Select tools from the left-side double-column toolbar or toggle between them quickly using keyboard hotkeys.

Icon Tool Name Hotkey Action Description
Selection Tool V Click to select shapes, drag bounding box corners to scale, or drag outside selection to rotate. Drag a marquee to multi-select.
Direct Selection A Directly select, move, and edit shape anchor points or pull Bezier curves using handle extensions.
Pen Tool P Place path anchors on mouse click; drag to extend handles for curving paths. Close the path by clicking the start point. Hitting Enter completes an open path.
Type Tool T Click anywhere on the artboard to open a prompt and drop scalable text blocks.
Line Tool \ Draw straight vector lines between two coordinate points.
Rectangle Tool M Drag to draw rectangular shapes (hold Shift for a perfect square). Click once on the canvas to open a dimension prompt to enter exact width and height values.
Ellipse Tool L Drag to draw circles or ellipses (hold Shift for a perfect circle). Click once on the canvas to open a dimension prompt to enter exact width and height values.
Pencil / Brush B or N Freeform drawing. Smooths paths automatically and closes them upon mouse release for clean shapes.
Eraser Tool Shift + E Drag the eraser circle over selected paths to split them or carve out segments.
Rotate Tool R Select shape(s) and drag outside the center pivot marker to rotate selected items.
Hand Tool H or Space Hold the Spacebar or switch to Hand tool and drag your mouse to pan around the canvas.
Zoom Tool Z Click to zoom in. Hold Alt and click to zoom out. Drag right to zoom in dynamically, drag left to zoom out dynamically.

🎨 Premium & Advanced Features

Discover built-in workflows designed to match professional vector editing environments.

Adobe Illustrator-Style Dynamic Zoom

Select the Zoom Tool (Z) and drag your mouse to the right to continuously zoom in, or drag to the left to zoom out. The zooming focuses perfectly on the click origin coordinates, locking the point under your mouse cursor.

Smart SVG Import & Artboard Matching

Open/Import SVG files automatically updates the workspace artboard bounds to match the viewBox of the imported file. It strips duplicate background graphics, centering files cleanly and importing vector data as individual selectable elements.

Dynamic Hierarchical Layers

Open sub-items showing paths, lines, and shape classes within layers. Lock individual sub-elements, toggle visibility, select target elements directly by clicking the target circle, or execute stack order operations.

Alt-Drag Duplication

Press and hold the Alt key (or toggle Virtual Alt on the modifier keypad) while dragging items with the Selection Tool to immediately duplicate shapes on mouse up.

Draggable Virtual Modifier Keypad

A translucent draggable modifier keypad floats at the bottom part of the screen. Toggle Ctrl, Alt, or Shift to lock modifier keys on without needing to hold down keyboard buttons. Highly useful for laptop trackpads or touchscreen devices.

Pencil Close & Select

The Pencil Tool (B / N) automatically completes freehand segments by closing the path loop. Paths are rendered in fully-selected mode immediately, making anchors and bezier points accessible for refinement.

Top Control Properties

  • Fill and Stroke Swatches: Click and choose colors via swatches or input hex values. Click the overlapping preview box to swap active color focus.
  • Document Size & Unit Converters: Adjust the workspace artboard width, height, and unit metrics (pixels, inches, cm, mm). If physical units are selected, changing the PPI scales the artboard accordingly.
  • Align Panels: Select shape layers and quickly align them relative to the artboard limits or to the collective bounding box of the active selection.

🚀 iGuhit Vector Graphics Editor

A premium, fully client-side vector graphics editor built with HTML5, CSS3, JavaScript, and Paper.js — designed to match professional vector design environments like Industry Standard Applications. Now with a built-in multi-provider AI Agent.

Juan Salgarino
Creator & Lead Developer — iGuhit Vector
This software is created by Juan Salgarino, the first Filipino programmer who built a Graphics Design Software. iGuhit Vector represents a landmark achievement in Philippine software development — a fully-featured, browser-based vector graphics suite engineered entirely from scratch.

Introduction

iGuhit Vector replicates the traditional multi-panel desktop vector workspace. Draw path vectors, modify anchor points, manage layers, apply gradients and patterns, embed images, and export to SVG, PDF, PNG, and Adobe Illustrator format — all inside a browser tab. In v5, an AI Agent gives you natural-language control of the entire canvas.

Canvas & Artboard

The canvas is an endless pasteboard. The white rectangle is your exportable Artboard. Draw anywhere on the canvas; only content within an artboard is exported to PDF/PNG.

File Structure

  • index.html — Workspace markup: menus, panels, toolbar, canvas, ruler strips, AI Agent panel.
  • style.css — Dark UI theme, panel layouts, animation keyframes.
  • app.js — Core engine: all tools, layer system, undo/redo, artboard, exports.
  • advanced-features-addon.js — Pathfinder, blob brush, boolean previews.
  • iguhit-enhancements.js — Rulers, smart guides, arrowheads, step & repeat, artboard tool, AI import/export.
  • iguhit-features.js — v4 Gradient fill, pattern fill, symbol library, snap to grid, image embed, tapered brush, PNG per artboard.
  • iguhit-ai-agent.js — v5 Multi-provider AI Agent (Claude, Gemini, ChatGPT) with full canvas control, retry logic, and rate-limit handling.

Quick Workflow

  1. Pick a tool from the left toolbar (or use its keyboard shortcut).
  2. Draw on the canvas. Use the top control bar to set fill, stroke, opacity.
  3. Open the Adv tab in the right panel for gradients, patterns, symbols, and image placement.
  4. Click the ✦ AI Agent button in the top menu to open the AI chat panel.
  5. Use File menu to export as SVG, PDF, PNG, or Illustrator file.

🎨 Core Features

The foundational capabilities built into iGuhit Vector.

Hierarchical Layers

Create multiple layers. Each has visibility, lock, color indicator, expand/collapse, rename (double-click), and a radio button to select all items in that layer.

Full Bezier Pen Tool

Click to place corners, drag to curve. Works identically to Illustrator's Pen Tool including handle pull-out on placement.

Pathfinder

Unite, Subtract, Intersect, and Exclude overlapping paths. Boolean preview shows the result before committing.

Alignment

Align selected objects to selection bounds or to the artboard. Detects which artboard the items are inside automatically.

Rulers (inches)

Horizontal and vertical rulers in red, defaulting to inches. Update live on zoom and pan. Toggle with Ctrl+R.

Smart Guides

Magenta snap lines appear when dragging near edges or centers of other objects. Toggle via View menu.

Unlimited Undo/Redo

30-step undo/redo stack. Autosaves to localStorage every 10 seconds and on page close.

Step & Repeat

In the Properties panel: set Count, ΔX, ΔY and duplicate selected objects N times with cumulative offsets. Ctrl+D repeats last action.

Control Bar

The control bar at the top is context-sensitive. It shows different controls based on the active tool:

  • Type Tool active / text selected — Font Family, Size, Weight, Style
  • Rect Tool / path selected — Corner Radius TL/TR/BR/BL with Link toggle
  • Direct Select active — Segment Type: Smooth, Corner, ←In, Out→
  • Artboard Tool active — Selected artboard name, W/H resize inputs, Delete button
  • Always visible — Fill, Stroke, Width, Style, Arrow Start/End, Opacity, Align, Artboard size, PPI

Math Expressions

Any numeric input field accepts math expressions. Type 100/3, 24*2+4, or (50+30)*2 then press Enter to evaluate.

🎨 Gradient & Pattern Fill v4 New

Apply linear/radial gradients and tiled pattern fills to any selected object — found in the Advanced panel (Adv tab).

Gradient Fill

Select one or more objects, then open the Adv panel → Gradient Fill → Apply Gradient Fill…

Linear Gradient

Pick two colors (Color 1 and Color 2), set the position of each stop (0–100%), and set the Angle slider (0–360°) to control the direction. Click Apply Gradient.

Radial Gradient

Same color controls as linear. The gradient radiates outward from the object's center to its right edge.

SVG Compatible

Gradients are applied as native Paper.js gradient objects and export correctly to SVG and PDF.

Pattern Fill

Select objects, then Adv panel → Pattern Fill → Apply Pattern Fill…

Five built-in patterns: Dots, Lines, Grid, Diagonal, Checker. Pick a Color and tile Size before clicking Apply.

🧩 Symbol Library v4 New

Save selections as reusable symbols and place them anywhere on the canvas.

Saving a Symbol

  1. Select the objects you want to save.
  2. Open Adv panel → Symbol Library → Open Symbol Library…
  3. Type a name in the text field and click + Save Selection as Symbol.

Placing a Symbol

Click Place on any symbol card. A copy is placed at the canvas center, fully selected and ready to move.

Deleting a Symbol

Click Del on the symbol card. This only removes it from the library — any copies already placed on the canvas remain.

Session Storage

Symbols are stored for the current browser session. Export your canvas as SVG before closing to preserve all artwork.

⊞ Snap to Grid v4 New

Align drawing operations precisely to a configurable grid overlay.

Enabling Snap to Grid

Go to Adv panel → Snap to Grid → Toggle Snap to Grid, or press Ctrl+Shift+\. A blue dot-grid overlay appears on the canvas.

Grid Size

Enter a value (in paper pixels) in the px input next to the toggle button. Default is 10px.

How Snapping Works

When snap is enabled, all draw operations snap anchor points to the nearest grid intersection:

snapped = round(paperPoint / gridSize) * gridSize

Tip

Combine Snap to Grid with Smart Guides for both grid-aligned and object-aligned placement at the same time.

🖼️ Image Embed (Place) v4 New

Import raster images (PNG, JPG, GIF, WebP, SVG) directly onto the canvas as embedded objects.

Placing an Image

  • File menu → Place / Embed Image…
  • Adv panel → Image → Place / Embed Image…

The image is embedded as a Paper.js Raster object centered on the canvas view.

Auto-Scaling

If the image is larger than the artboard, it is automatically scaled down to 80% of the artboard's smaller dimension while maintaining aspect ratio.

Embedded vs Linked

Images are embedded as base64 data URIs — the file is self-contained. No external file links are used.

🖌️ Tapered Brush v4 New

Draw variable-width freehand strokes that taper to a point — converted to fully scalable vector shapes.

Using the Tapered Brush

  1. Click the paintbrush icon in the toolbar or press Shift+B.
  2. Set your desired Stroke Width in the control bar — this becomes the starting width.
  3. Set your desired Stroke Color — this becomes the fill of the resulting shape.
  4. Click and drag on the canvas to draw.
  5. Release the mouse — the stroke is converted to a filled vector shape.

How it Works

Unlike the Pencil tool which creates a stroked path, the Tapered Brush builds a filled shape by computing offset curves on both sides of the stroke path. The width decreases from the starting stroke width to ~0.4px at the tip.

Tip — Smoothing

The Tapered Brush automatically applies catmull-rom smoothing to the underlying path. For cleaner strokes, draw slowly and deliberately.

📤 Export Options

All the ways to get your artwork out of iGuhit Vector.

Export as SVG

File → Save / Export SVG — Exports all visible content as a standard SVG file. Fully editable in any SVG editor.

Export as Illustrator (.svg)

File → Export as Illustrator (.svg) — Includes Adobe Illustrator-compatible XML namespaces. Open directly in Illustrator as an editable document.

Import Illustrator (.ai / .svg)

File → Import Illustrator (.ai / .svg) — Opens a file picker for .ai and .svg files. Modern AI files (CS3+) are SVG-based and import as fully editable paths.

Export as PNG

File → Export as PNG — Exports the entire canvas view as a flat raster image.

Export PNG per Artboard v4 New

Exports each artboard as its own separate PNG file at 2× resolution. Files are named Artboard-1.png, Artboard-2.png, etc.

Export PDF (Artboard)

Generates a vector PDF using raw PDF content stream operators. Each artboard becomes one PDF page. Paths, curves, fills, and strokes are written as real PDF vector commands — open in Illustrator and edit paths directly.

Print Quality

The PDF export writes real Bézier curve commands (m, l, c, f, S, B) directly — no rasterization. Artwork prints at full printer resolution.

✦ AI Agent v5 New

A built-in multi-provider AI assistant that has full control of your iGuhit canvas. Just describe what you want — the agent draws, arranges, styles, and edits for you.

What the AI Agent Can Do

The agent can draw shapes, create complex illustrations, apply colors and gradients, group objects, create cropmarks, align items, undo/redo, and more — all from a plain text prompt. It reads the current canvas state before every reply so it always knows what's on screen.

Click the orange ✦ AI Agent button in the top menu bar. The panel appears at the bottom-right of the screen. You can drag it by its header to reposition it, resize it from the corner, minimize it (−), or close it (×).

🔑 Setup & API Keys

The AI Agent connects directly to AI provider APIs from your browser. You need an API key from at least one provider.

Privacy & Security

Your API keys are stored only in your browser's localStorage. They are sent directly from your browser to the respective AI provider — never to any third-party server.

First Launch

On first open (or when no key is saved), the agent panel automatically shows the Settings → API Keys screen. Enter your key there and click Save.

Accessing Settings Later

Click the ⚙ gear icon in the agent panel header at any time to open settings. It has three tabs: Provider, Model, and API Keys.

Changing or Clearing a Key

Open ⚙ Settings → API Keys, update the input field, and click Save. To clear a key, click the ✕ button next to the input. A cleared key means that provider cannot be used until a new key is entered.

Running from a Local Server

The AI Agent uses fetch() to call external APIs. This requires the page to be served over HTTP, not opened directly as a file:// URL. Run iGuhit from a local server: python -m http.server 8080 or use VS Code Live Server.

All coordinates are artboard-relative: (0, 0) = top-left corner of the artboard. The default artboard is 2550 × 3300 px (8.5 × 11 in at 300 PPI). Center = (1275, 1650). Keep shapes within 0–2550 x and 0–3300 y.

💡 Tips & Rate Limits

Getting the best results from the AI Agent, and how rate limits are handled.

Writing Good Prompts

  • Be specific about position — "in the center", "top-left corner", "below the circle" all help the agent place things correctly.
  • Name colors — "bright red", "#ff6b6b", "dark navy blue" all work well.
  • Break big tasks into steps — "First draw the background shapes, then add the text" gives better results than one giant request.
  • Reference existing items — "Select the rectangle I just drew and make it blue" works because the agent sees the canvas state.
  • Ask follow-up questions — The agent remembers the last 7 exchanges, so you can refine your request: "Make the eyes bigger" after drawing a face.

Rate Limit Handling

The agent handles API rate limits (HTTP 429) automatically with exponential backoff and model fallback:

  1. On first 429 — waits 15 seconds, shows a live countdown, then retries
  2. On second 429 — waits 30 seconds
  3. On third 429 — waits 60 seconds
  4. If all retries fail on the current model — automatically switches to the next lighter model in the fallback chain
  5. If all models are exhausted — shows a friendly error with upgrade options

✸ Gemini Free Tier Limits

Google's free Gemini tier allows approximately 2 requests per minute and 50 requests per day. If you use the agent frequently, consider upgrading at aistudio.google.com/plan or switching to Claude or ChatGPT for higher limits.

Tip — Reduce Prompt Size

Shorter, focused prompts use fewer tokens and are less likely to hit rate limits. Instead of describing your entire project in one message, break it into smaller tasks.

Known Limitations

  • The agent cannot read pixel content of raster images placed on the canvas — it can move or delete them but not describe their visual content.
  • Very complex illustrations (100+ shapes) may take multiple rounds of prompting to refine.
  • The agent works best when iGuhit is run from a local HTTP server, not a file:// URL.
  • Conversation history is kept in memory — it resets if you reload the page. Use the ⟳ clear button to manually reset context when starting a new project.

Switching Providers Mid-Session

Open ⚙ Settings → Provider, select a different provider, and click Save. The chat resets and the header updates to reflect the new provider color and icon. All three providers use the same set of canvas commands, so the agent's capability is identical regardless of which one you choose.

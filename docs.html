🚀 iGuhit Vector Graphics Editor

A premium, fully client-side vector graphics editor built with HTML5, CSS3, JavaScript, and Paper.js — designed to match professional vector design environments like Adobe Illustrator.

Juan Salgarino
Creator & Lead Developer — iGuhit Vector
This software is created by Juan Salgarino, the first Filipino programmer who built a Graphics Design Software. iGuhit Vector represents a landmark achievement in Philippine software development — a fully-featured, browser-based vector graphics suite engineered entirely from scratch.

Introduction

Welcome to iGuhit Vector! This application replicates the traditional multi-panel desktop workspace. You can draw path vectors, modify control anchor points, manage complex layer hierarchies, and style layouts using advanced fills, strokes, and effects.

Canvas & Artboard

The canvas acts as an endless pasteboard. The white rectangle represents your exportable Artboard. Draw anywhere — on or off-artboard — and zoom/pan freely just like in professional vector suites.

File Structure

  • index.html — Workspace markup: menus, panels, toolbar, canvas container.
  • style.css — Dark UI theme, input styles, panel layouts, animation keyframes.
  • app.js — Core engine: tools, mouse handlers, layer system, undo/redo, exports.
  • advanced-features-addon.js — Pathfinder operations, blob brush, boolean previews.
  • iguhit-enhancements.js — Rulers, smart guides, arrowheads, step & repeat, artboard tool, AI import/export.

Running the App

The app runs 100% client-side. Serve from a local server or open index.html directly in a modern browser (Chrome / Edge recommended for best Paper.js performance).

Local server: http://localhost:8000

Quick Workflow

  1. Select a tool from the left toolbar (or press its keyboard shortcut).
  2. Draw on the canvas. Use the control bar at the top to set fill, stroke, and opacity.
  3. Switch to the Selection Tool (V) to move and transform objects.
  4. Use File → Export SVG / PNG / PDF to save your work.

🎨 Core Features

The complete set of built-in capabilities in iGuhit Vector.

Hierarchical Layer System

Create and manage multiple layers. Each layer has its own visibility toggle (eye icon), lock state, color indicator, and expand/collapse children. Double-click a layer name to rename it inline.

Dynamic Zoom & Pan

Drag the Zoom Tool right/left for continuous dynamic zoom. Use Alt+Scroll to zoom from any tool. Hold Space to pan temporarily without switching tools.

Full Bezier Pen Tool

Click to place corner points, drag to create curved handles. Close paths by clicking the starting anchor. Works identically to the Illustrator Pen Tool, including handle drag-out on placement.

Pathfinder Operations

Unite, Subtract, Intersect, and Exclude overlapping vector shapes using the Advanced panel. Boolean preview mode shows a transparent overlay before committing.

Alt-Drag Duplication

Hold Alt while dragging selected objects to instantly duplicate them on mouse release. Works with the virtual modifier keypad for tablet/touch use.

Multi-Format Export

Export as SVG (editable), PNG (flat raster), PDF (artboard-bounded, one page per artboard), or Adobe Illustrator-compatible SVG. Import SVG and AI files directly.

Alignment System

Align selected objects to the selection bounding box or to the artboard edges: left, center-H, right, top, center-V, and bottom alignment buttons in the control bar.

Unlimited Undo / Redo

Up to 30-step undo history (Ctrl+Z) and redo (Ctrl+Y). State is also autosaved to localStorage every 10 seconds and on page unload.

Control Bar Properties

  • Fill & Stroke: Color pickers + "No Fill / No Stroke" ban buttons. Click the toolbar color indicators to swap active focus between fill and stroke.
  • Stroke Style: Solid or Dashed. Arrow start/end dropdowns: None, Triangle arrow, or Circle. Arrowheads are rendered as actual vector shapes on every path that has them set.
  • Opacity: Range slider with live percentage display.
  • Artboard Size & Unit: Set width, height, and unit (px, in, cm, mm). The ruler automatically displays in the selected unit with the correct scale.
  • Math Expressions: Any numeric input field accepts math expressions (e.g. 100/3, 12*4+5). Press Enter to evaluate.

⭐ New & Enhanced Features

All features added and fixed in the latest update (v3.0).

Rulers New

Horizontal and vertical rulers now border the canvas workspace. Ruler tick marks, labels, and minor ticks all automatically match the currently selected artboard unit — pixels, inches, centimeters, or millimeters — scaled to the correct PPI. Toggle rulers on/off with Ctrl+R or View → Toggle Rulers. Rulers update live as you zoom and pan.

Smart Guides New

When dragging objects, magenta guide lines snap and appear when an object's edge or center aligns with any other object's edge or center, and with the artboard edges. Guides are rendered as SVG lines directly over the canvas for guaranteed visibility. Snapping auto-clears after 700ms. Toggle via View → Toggle Smart Guides.

Tip

Smart Guides snap to left, center-X, right, top, center-Y, and bottom edges of all visible objects and the artboard simultaneously.

Type Tool — Font Controls Fixed

When the Type Tool is active, the control bar now correctly shows: Font Family (13 system fonts), Font Size, Font Weight (Light / Regular / Semibold / Bold / Black), and Font Style (Normal / Italic). Selecting an existing text object syncs all controls to that object's settings. Changing any control immediately updates the selected text.

Corner Radius (Rectangle) Fixed

When the Rectangle Tool is active or any path is selected, the control bar shows four corner radius inputs (TL, TR, BR, BL) with a Link toggle button. When linked, all four corners update together. Unlink to set individual radii. Uses Adobe Illustrator's Bezier approximation for circular arcs (k = 0.5523). Corner data is stored on the path and re-synced when the object is re-selected. Supports math expressions.

Direct Selection — Segment Type Buttons Fixed

When the Direct Selection Tool is active, the control bar shows four segment-type buttons:

  • Smooth — Applies catmull-rom smooth handles to selected segments
  • Corner — Removes both handles, creating a sharp corner point
  • ← In — Keeps the in-handle, zeros out the out-handle
  • Out → — Keeps the out-handle, zeros out the in-handle

Artboard Tool New

Press Shift+A or click the Artboard Tool in the toolbar. Click any artboard on the canvas to select it — it highlights in orange. Press Delete or click the Delete button in the control bar to remove secondary artboards. The main artboard is protected from deletion. Selection persists across tool switches — switching to another tool and back to the Artboard Tool remembers the last selected artboard.

Add New Artboard Fixed

Clicking Add New Artboard in the Advanced panel now creates only the artboard visual — no rogue path object is created in the draw layer. New artboards are placed in a grid layout with proper spacing.

Layer Radio Button & Visibility Toggle Fixed

Each layer row in the Layers panel now shows a radio-style circle on the left. Click it to select all items in that layer; click again to deselect all. The eye icon on every layer toggles visibility — clicking it hides/shows all objects in that layer at once.

Layer Rename on Double-Click New

Double-click any layer name in the Layers panel to make it editable inline. Press Enter or click away to save. The name updates on the Paper.js layer object immediately.

Adobe Illustrator Import & Export New

  • File → Import Illustrator (.ai / .svg) — Opens a file picker for .ai and .svg files. Modern AI files (CS3+) are SVG internally and import as fully editable paths.
  • File → Export as Illustrator (.svg) — Exports your artwork as an SVG with full Adobe Illustrator-compatible XML namespaces (xmlns:a, sfw metadata block, xml:space="preserve") that Illustrator opens as an editable document.

PDF Export — Artboard-Bounded, Single Download Fixed

PDF export now renders only the artboard region (not the full canvas) by projecting artboard coordinates to screen pixels and drawing just that region. Multiple artboards each get their own PDF page at the correct dimensions. Duplicate download bug fixed — there is now exactly one event listener wired to the export button.

Cropmarks Fixed

Generate cropmarks (Object → Create Cropmarks) from any selected object. Cropmarks match Adobe Illustrator's spec: 0.25pt black strokes, 8.5pt gap, 14pt length, placed at all four corners. All eight lines are automatically grouped into a single named group ("Crop Marks") so your layer list stays clean.

Arrowheads Fixed

Arrow Start and Arrow End dropdowns in the control bar now draw actual vector arrowheads (filled triangles or circles) at the endpoints of any path that has them set. Arrowheads update on every view redraw and sync correctly when you select a path that already has arrow data.

Step & Repeat New

Found in the Properties panel. Select one or more objects, set a Count, ΔX (horizontal offset), and ΔY (vertical offset), then click Step & Repeat. The selected objects are duplicated Count times with each copy offset by ΔX/ΔY from the previous. Press Ctrl+D to repeat the last Step & Repeat operation, or click Repeat Last.

Button Animations & Sound Effects New

Every button in the application shows a ripple wave animation on click. A Web Audio API synthesizer plays a unique tone per button type: tool buttons play a descending sine sweep, action buttons play a rising triangle tone. No audio files required.

Math Expression Evaluator New

Type any math expression into any numeric input field and press Enter to evaluate it: 100/3, 24*2+4, (50+30)*2. Works in stroke width, font size, corner radius, transform fields, artboard dimensions, and all other inputs.

📐 Panels & UI Reference

Every panel, tab, and control area explained.

Right Sidebar Tabs

The right sidebar has four tabs, toggled by clicking the tab button or the icon strip on the far right:

  • Layers — Layer hierarchy with expand/collapse, visibility, lock, rename, radio (select-all), and layer target.
  • Properties — Transform (X, Y, W, H), Stroke Cap/Join, Dash Array, Rotate, Flip, Duplicate, and Step & Repeat.
  • Swatches — Predefined color palette. Click a swatch to apply to the active fill or stroke.
  • Advanced — Pathfinder (Unite, Subtract, Intersect, Exclude), Path Operations (Offset, Expand, Live Corners), Boolean Preview, and Add New Artboard.

Control Bar (Top)

The control bar is context-sensitive and shows different groups depending on the active tool and selection:

  • Type Tool active / text selected: Font Family, Size, Weight, Style
  • Rect Tool active / path selected: Corner Radius (TL/TR/BR/BL) with Link toggle
  • Direct Select Tool active: Segment Type buttons (Smooth, Corner, ←In, Out→)
  • Artboard Tool active: Selected artboard name + Delete button
  • Always visible: Fill, Stroke, Stroke Width, Stroke Style, Arrow Start/End, Opacity, Align, Artboard Size, PPI

Floating Virtual Modifier Keypad

The draggable keypad in the bottom area provides toggleable Ctrl, Alt, and Shift keys. Useful for tablet, touchscreen, or single-hand input. Active modifiers glow orange. Drag the header to reposition.

Status Bar (Bottom)

Shows the active tool name, live cursor coordinates (updated on mouse move), canvas hints, and the zoom percentage input (editable — type a value and press Enter).

Rulers

Horizontal and vertical rulers are displayed at the top and left edges of the canvas viewport. Tick marks are labeled in the current artboard unit (px, in, cm, mm) and update as you zoom and pan. Toggle with Ctrl+R.

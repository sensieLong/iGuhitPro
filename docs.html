🚀 iGuhit Vector Graphics Editor

A premium, fully client-side vector graphics editor built with HTML5, CSS3, JavaScript, and Paper.js — designed to match professional vector design environments like Industry Standard Applications.

Juan Salgarino
Creator & Lead Developer — iGuhit Vector
This software is created by Juan Salgarino, the first Filipino programmer who built a Graphics Design Software. iGuhit Vector represents a landmark achievement in Philippine software development — a fully-featured, browser-based vector graphics suite engineered entirely from scratch.

Introduction

iGuhit Vector replicates the traditional multi-panel desktop vector workspace. Draw path vectors, modify anchor points, manage layers, apply gradients and patterns, embed images, and export to SVG, PDF, PNG, and Adobe Illustrator format — all inside a browser tab.

Canvas & Artboard

The canvas is an endless pasteboard. The white rectangle is your exportable Artboard. Draw anywhere on the canvas; only content within an artboard is exported to PDF/PNG.

File Structure

  • index.html — Workspace markup: menus, panels, toolbar, canvas, ruler strips.
  • style.css — Dark UI theme, panel layouts, animation keyframes.
  • app.js — Core engine: all tools, layer system, undo/redo, artboard, exports.
  • advanced-features-addon.js — Pathfinder, blob brush, boolean previews.
  • iguhit-enhancements.js — Rulers, smart guides, arrowheads, step & repeat, artboard tool, AI import/export.
  • iguhit-features.js — v4 Gradient fill, pattern fill, symbol library, snap to grid, image embed, tapered brush, PNG per artboard.

Quick Workflow

  1. Pick a tool from the left toolbar (or use its keyboard shortcut).
  2. Draw on the canvas. Use the top control bar to set fill, stroke, opacity.
  3. Open the Adv tab in the right panel for gradients, patterns, symbols, and image placement.
  4. Use File menu to export as SVG, PDF, PNG, or Illustrator file.

🎨 Core Features

The foundational capabilities built into iGuhit Vector.

Hierarchical Layers

Create multiple layers. Each has visibility, lock, color indicator, expand/collapse, rename (double-click), and a radio button to select all items in that layer.

Full Bezier Pen Tool

Click to place corners, drag to curve. Works identically to Illustrator's Pen Tool including handle pull-out on placement.

Pathfinder

Unite, Subtract, Intersect, and Exclude overlapping paths. Boolean preview shows the result before committing.

Alignment

Align selected objects to selection bounds or to the artboard. Detects which artboard the items are inside automatically.

Rulers (inches)

Horizontal and vertical rulers in red, defaulting to inches. Update live on zoom and pan. Toggle with Ctrl+R.

Smart Guides

Magenta snap lines appear when dragging near edges or centers of other objects. Toggle via View menu.

Unlimited Undo/Redo

30-step undo/redo stack. Autosaves to localStorage every 10 seconds and on page close.

Step & Repeat

In the Properties panel: set Count, ΔX, ΔY and duplicate selected objects N times with cumulative offsets. Ctrl+D repeats last action.

Control Bar

The control bar at the top is context-sensitive. It shows different controls based on the active tool:

  • Type Tool active / text selected — Font Family, Size, Weight, Style
  • Rect Tool / path selected — Corner Radius TL/TR/BR/BL with Link toggle
  • Direct Select active — Segment Type: Smooth, Corner, ←In, Out→
  • Artboard Tool active — Selected artboard name, W/H resize inputs, Delete button
  • Always visible — Fill, Stroke, Width, Style, Arrow Start/End, Opacity, Align, Artboard size, PPI

Math Expressions

Any numeric input field accepts math expressions. Type 100/3, 24*2+4, or (50+30)*2 then press Enter to evaluate.

🎨 Gradient & Pattern Fill v4 New

Apply linear/radial gradients and tiled pattern fills to any selected object — found in the Advanced panel (Adv tab).

Gradient Fill

Select one or more objects, then open the Adv panel → Gradient Fill → Apply Gradient Fill…

Linear Gradient

Pick two colors (Color 1 and Color 2), set the position of each stop (0–100%), and set the Angle slider (0–360°) to control the direction. Click Apply Gradient.

Radial Gradient

Same color controls as linear. The gradient radiates outward from the object's center to its right edge. Switch to Radial mode by clicking the Radial button.

SVG Compatible

Gradients are applied as native Paper.js gradient objects and export correctly to SVG. In the PDF export they are rendered as vector gradients.

Pattern Fill

Select objects, then Adv panel → Pattern Fill → Apply Pattern Fill…

Five built-in patterns:

  • Dots — repeating circles
  • Lines — horizontal stripes
  • Grid — horizontal and vertical grid lines
  • Diagonal — 45° diagonal lines
  • Checker — checkerboard squares

Pick a Color and Size (tile size in px) before clicking Apply. The pattern is clipped to the exact boundary of each selected shape.

🧩 Symbol Library v4 New

Save selections as reusable symbols and place them anywhere on the canvas — found in the Adv panel.

Saving a Symbol

  1. Select the objects you want to save.
  2. Open Adv panel → Symbol Library → Open Symbol Library…
  3. Type a name in the text field.
  4. Click + Save Selection as Symbol.

The symbol appears as a card in the library grid.

Placing a Symbol

Click Place on any symbol card. A copy is placed at the canvas center, fully selected and ready to move. The original symbol in the library is unaffected — you can place it as many times as you need.

Deleting a Symbol

Click Del on the symbol card. This only removes it from the library — any copies already placed on the canvas remain.

Session Storage

Symbols are stored for the current browser session. To persist symbols across sessions, export your canvas as SVG (which preserves all artwork) before closing.

⊞ Snap to Grid v4 New

Align drawing operations precisely to a configurable grid overlay.

Enabling Snap to Grid

Go to Adv panel → Snap to Grid → Toggle Snap to Grid, or press Ctrl+Shift+\. A blue dot-grid overlay appears on the canvas. The button border turns orange when active.

Grid Size

Enter a value (in paper pixels) in the px input next to the toggle button. The grid updates immediately. Default is 10px.

How Snapping Works

When snap is enabled, all draw operations snap anchor points to the nearest grid intersection. This works for the Pen, Rectangle, Ellipse, Line, and Pencil tools. The snap point is computed as:

snapped = round(paperPoint / gridSize) * gridSize

Tip

Combine Snap to Grid with Smart Guides for both grid-aligned and object-aligned placement at the same time.

🖼️ Image Embed (Place) v4 New

Import raster images (PNG, JPG, GIF, WebP, SVG) directly onto the canvas as embedded objects.

Placing an Image

Use either:

  • File menu → Place / Embed Image…
  • Adv panel → Image → Place / Embed Image…

A file picker opens. Select any image file. The image is embedded as a Paper.js Raster object, centered on the canvas view.

Auto-Scaling

If the image is larger than the artboard, it is automatically scaled down to 80% of the artboard's smaller dimension while maintaining aspect ratio.

Working with Embedded Images

Once placed, images behave like any other canvas object:

  • Use the Selection Tool (V) to move and scale.
  • Apply opacity via the control bar.
  • Use Object → Bring to Front / Send to Back to control stacking order.
  • Images are included in SVG, PDF, and PNG exports.

Embedded vs Linked

Images are embedded as base64 data URIs — the file is self-contained. No external file links are used, so moving or renaming the original file has no effect.

🖌️ Tapered Brush v4 New

Draw variable-width freehand strokes that taper to a point — converted to fully scalable vector shapes.

Using the Tapered Brush

  1. Click the paintbrush icon in the toolbar or press Shift+B.
  2. Set your desired Stroke Width in the control bar — this becomes the starting width of the stroke.
  3. Set your desired Stroke Color — this becomes the fill of the resulting shape.
  4. Click and drag on the canvas to draw. You'll see the live stroke path as you paint.
  5. Release the mouse — the stroke is converted to a filled vector shape that tapers from full width to a fine point.

How it Works

Unlike the Pencil tool which creates a stroked path, the Tapered Brush builds a filled shape by computing offset curves on both sides of the stroke path. The width decreases from the starting stroke width to ~0.4px at the tip. The result is a Paper.js Path with a closed fill — no stroke — that scales perfectly at any zoom level without getting thicker or thinner.

Tip — Smoothing

The Tapered Brush automatically applies catmull-rom smoothing to the underlying path before building the shape. For cleaner strokes, draw slowly and deliberately.

After Drawing

The resulting shape can be manipulated with the Direct Selection Tool to adjust individual anchor points, or grouped with other objects, given gradients or pattern fills, and exported to any format.

📤 Export Options

All the ways to get your artwork out of iGuhit Vector.

Export as SVG

File → Save / Export SVG — Exports all visible content as a standard SVG file. Fully editable in any SVG editor. Gradients, text, and paths are preserved as vector data.

Export as Illustrator (.svg)

File → Export as Illustrator (.svg) — Same as SVG export but includes Adobe Illustrator-compatible XML namespaces (xmlns:a, sfw metadata block). Open directly in Illustrator as an editable document.

Import Illustrator (.ai / .svg)

File → Import Illustrator (.ai / .svg) — Opens a file picker for .ai and .svg files. Modern AI files (CS3+) are SVG-based and import as fully editable paths.

Export as PNG

File → Export as PNG — Exports the entire canvas view as a flat raster image.

Export PNG per Artboard v4 New

File → Export PNG per Artboard or Adv panel → Export → Export PNG per Artboard

Exports each artboard as its own separate PNG file at 2× resolution (Retina/HiDPI quality). Files are named Artboard-1.png, Artboard-2.png, etc. Artboard chrome (grid lines, shadow, border) is hidden during capture. Multiple files download sequentially.

Export PDF (Artboard)

File → Export PDF — Generates a vector PDF using raw PDF content stream operators. Each artboard becomes one PDF page at its exact dimensions. Paths, curves, fills, and strokes are written as real PDF vector commands — open in Illustrator and edit paths directly. Text is embedded as PDF text operators.

Print Quality

The PDF export writes real Bézier curve commands (m, l, c, f, S, B) directly — no rasterization. Artwork prints at full printer resolution regardless of file size.

📐 Panels & UI Reference

Every panel, tab, and UI area explained.

Right Sidebar Tabs

  • Layers — Layer hierarchy with visibility eye, lock, rename (double-click), radio button (select-all), and expand/collapse children.
  • Properties — Transform X/Y/W/H, Stroke Cap/Join, Dash Array, Rotate, Flip, Duplicate, and Step & Repeat.
  • Swatches — Predefined color palette. Click to apply to active fill or stroke.
  • Adv — Pathfinder, Path Operations, Artboards, Gradient Fill, Pattern Fill, Symbol Library, Place Image, Snap to Grid, Export PNG per Artboard.

Rulers

Red tick-mark rulers run along the top and left edges of the canvas. Default unit is inches at 96 PPI. Rulers update on every zoom and pan. Toggle with Ctrl+R. Change unit via the artboard unit dropdown in the control bar.

Smart Guides

Magenta SVG lines snap over the canvas when dragging objects near edges or centers of other objects or the artboard. Auto-clears after 700ms. Toggle via View → Toggle Smart Guides.

Virtual Modifier Keypad

The floating draggable keypad provides toggleable Ctrl, Alt, Shift keys — useful for tablet or touchscreen use. Drag the header to reposition.

Status Bar

Shows active tool name, live cursor coordinates, canvas hints, and the zoom percentage input (type a value, press Enter to set).
